# 2110211 Introduction to Data Structure

Coursework, lecture code-alongs, and grader problem solutions for **2110211 Introduction to Data Structure** (Intania 108, Chulalongkorn University).

Everything here is written in **C++**, built with `clang`, and organized to mirror the course's teaching order: C++ fundamentals → `pair`/`vector` → `set`/`map` → `stack`/`queue`/`priority_queue` → competitive-programming (CP) style pair/vector patterns.

Each problem/lecture folder generally contains:
- one `.cpp` source file (named after the grader code, e.g. `d62_q1a_vote.cpp`)
- an `output/` folder with the compiled binary and its `.dSYM` debug symbols (macOS), generated by the VS Code C++ debugger — safe to ignore/regenerate, not meant to be hand-edited.

## Building & Running

This workspace is set up for VS Code + the C/C++ extension on macOS (see `.vscode/tasks.json`). To build any single file manually:

```bash
clang -g "path/to/file.cpp" -o "path/to/file"
./path/to/file
```

Or just open a `.cpp` file in VS Code and hit **Run/Debug** — the default build task (`C/C++: clang build active file`) handles it.
